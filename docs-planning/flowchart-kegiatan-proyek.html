Kegiatan disimpan di proyek

Usulan perbaikan no. 1 · 19 Okt 2026 · revisi 2: kegiatan dikunci · paket beda kegiatan = data salah, dibuat ulang
Masalah sekarang. Proyek tidak punya kolom kegiatan. Kegiatan diambil dari RO paket pertama, atau dari kegiatan balai kalau belum ada paket. Paket dalam satu proyek boleh beda kegiatan. Akibatnya template form, skor, dan saldo kegiatan bisa berpindah sendiri.

A. Membuat & mengubah proyek

flowchart TD
  A(["Buat proyek"]) --> B{"Akun balai/satker\npunya kegiatan?"}
  B -- Ya --> C["Kegiatan terisi otomatis\n& terkunci"]
  B -- Tidak --> D["Pengisi pilih kegiatan"]
  C --> E{"Kegiatan punya\ntemplate form?"}
  D --> E
  E -- Tidak --> F["Tidak bisa lanjut:\n'Form kegiatan ini belum disusun admin'"]
  E -- Ya --> G["Form tampil sesuai template kegiatan\n+ saldo kegiatan terlihat"]
  G --> H["Simpan: proyek.kegiatanId = kegiatan terpilih"]
  H --> I(["Proyek tersimpan (Draft)"])
  I --> J["Edit proyek: kegiatan TERKUNCI\n(form, SK/ISK, kategori, paket, saldo,\nskor, dan akses terikat kegiatan)"]
  J --> K["Salah pilih kegiatan?\nHapus proyek Draft, buat ulang"]

B. Menambah / mengubah paket

flowchart TD
  P(["Tambah / edit paket"]) --> Q["Pilihan KRO/RO hanya dari\nkegiatan proyek"]
  Q --> R["Isi alokasi per tahun"]
  R --> S{"Server: RO milik\nkegiatan proyek?"}
  S -- Tidak --> T["Ditolak:\n'RO bukan bagian kegiatan proyek'"]
  S -- Ya --> U{"Total semua paket di kegiatan itu\nper tahun ≤ saldo kegiatan?"}
  U -- Tidak --> V["Ditolak: 'Melebihi saldo kegiatan\n[kode] tahun [t]: sisa Rp ...'"]
  U -- Ya --> W(["Paket tersimpan"])

D. Data proyek lama (sekali jalan saat migrasi)

Aturan: Kegiatan → Proyek → Paket satu jalur. Semua paket dalam satu proyek pasti di kegiatan proyek itu. Paket untuk kegiatan lain = proyek lain (mulai dari pilih kegiatan).
flowchart TD
  M(["Setiap proyek lama"]) --> M1{"Punya paket?"}
  M1 -- Ya --> M2["kegiatanId = kegiatan RO paket pertama"]
  M1 -- Tidak --> M3["kegiatanId = kegiatan balai"]
  M2 --> M4{"Ada paket dengan RO
dari kegiatan lain?"}
  M4 -- Tidak --> M5(["Selesai"])
  M4 -- Ya --> M6["Paket itu ditandai 'Harus dibuat ulang'
(data lama yang salah)"]
  M6 --> M7["Pengisi buat dari awal:
pilih kegiatan → proyek → paket"]
  M7 --> M8["Paket lama dihapus"]

Keputusan

Kegiatan dikunci setelah proyek disimpan (disetujui 19 Okt 2026). Yang terikat kegiatan: template form & isian kolomnya, kategori proyek (valuasi & kinerja), Sasaran Kegiatan/ISK, KRO/RO/komponen paket, saldo, skor evaluasi, cakupan akses role.
Kenapa ada proyek "campuran": proyek belum menyimpan kegiatan (ditebak dari paket pertama/balai); saat tebakan kosong, dialog paket menampilkan semua RO; server tidak memeriksa; penyaring RO baru ada sejak 15 Okt. Perbaikan ini menutup ketiganya.
