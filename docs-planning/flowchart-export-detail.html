Export detail proyek ikut template

Pekerjaan no. 1 · 20 Okt 2026 · menunggu persetujuan
Sekarang. Tombol Export › Excel / PDF di detail proyek memakai daftar kolom tetap yang lama: Info Umum (nama, balai, kewenangan, sumber usulan, kebutuhan tanah, wilayah sungai, KP, skor), sheet Tahapan Dokumen (tahun Studi Layak/DED/LARAP/Dok. Lingkungan — sudah tidak ada di form), dan Alokasi.
Akibatnya isi file berbeda dengan yang tampil di layar: kolom tambahan buatan admin, FKB/FKW/MPA per tahun, valuasi A/B/C, rincian skor, realisasi, dokumen tidak ikut.
Usulan. Isi file = persis isi layar detail: bagian "Isi usulan" (urutan tab & kolom mengikuti form kegiatan proyek itu) + daftar Paket (rencana & realisasi per tahun). Angka ditulis penuh (sama dengan keputusan Laporan).

Isi file PDF (A4)

Kop: judul "Detail proyek", nama proyek, kode · kegiatan · balai · periode · status, dicetak oleh/tanggal.
Lalu satu tabel per tab (Kolom | Isi) dengan urutan sama seperti Excel, lalu halaman Paket mendatar (kolom sama dengan sheet Paket). Tanpa tanda tangan/pengesahan (sama dengan Laporan).
